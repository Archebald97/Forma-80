ФОРМА 80 — Android PWA v1.2

Содержимое ZIP: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.

Установка через GitHub Pages (нужен бесплатный аккаунт GitHub):
1. Создайте публичный репозиторий, например forma80-app.
2. В корень репозитория загрузите ВСЕ ПЯТЬ файлов из архива (не сам ZIP).
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Дождитесь появления адреса https://ИМЯ.github.io/forma80-app/ .
5. Откройте адрес на Android в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
6. Откройте установленную Форму 80 → Данные → Восстановить из файла → выберите резервную копию JSON от v1.1.
7. Проверьте историю, прогресс и работу в авиарежиме после первого успешного открытия приложения онлайн.

ВАЖНО:
- Репозиторий публичный: исходный код приложения виден всем. Личные записи в репозиторий не загружайте.
- Личные тренировки остаются в памяти браузера/установленного приложения на телефоне, не в GitHub.
- Сохранение в установленном PWA отделено от старого локального HTML: нужен импорт JSON.
- Не удаляйте старую v1.1 и резервную копию, пока не проверите импорт.
- Очищение данных сайта/приложения может удалить локальные записи. Регулярно экспортируйте копию.
- На GitHub Pages приложение доступно по публичному URL, без авторизации.
- Для обновлений замените файлы и измените версию CACHE в sw.js, чтобы гарантировать обновление автономного кэша.
